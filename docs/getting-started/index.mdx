## About BotrixAI

**BotrixAI helps you build voice AI agents with a drag-and-drop workflow builder.** Design the conversation, attach the tools it needs, connect a phone number, and put it on a call:
- **Visual workflow builder** - design the conversation as a flow, no code required
- **Bring your own models** - use your own provider keys, or the managed pipeline
- **Telephony included** - inbound and outbound calling across multiple providers
- **2-minute setup** - from zero to working voice bot in under 2 minutes

## Setting up

Get the platform up and running using Docker with a small startup script on your local computer. If you are looking to deploy the platform on a server different than your local machine, please check the [Deployment](deployment/introduction) section.

<Note>We collect anonymous usage data to improve the product. You can opt out by setting `ENABLE_TELEMETRY=false` before running the startup script.</Note>

<CodeGroup>
```bash macOS/Linux
curl -o docker-compose.yaml https://raw.githubusercontent.com/Jatin-35/dograh/main/docker-compose.yaml && curl -o start_docker.sh https://raw.githubusercontent.com/Jatin-35/dograh/main/scripts/start_docker.sh && chmod +x start_docker.sh && ./start_docker.sh
```
```powershell Windows
Invoke-WebRequest -OutFile docker-compose.yaml https://raw.githubusercontent.com/Jatin-35/dograh/main/docker-compose.yaml; Invoke-WebRequest -OutFile start_docker.ps1 https://raw.githubusercontent.com/Jatin-35/dograh/main/scripts/start_docker.ps1; .\start_docker.ps1
```
</CodeGroup>

<Tip>
**Using an AI coding agent?** If you work in **Claude Code** or **Codex**, install the official BotrixAI setup skill and let your agent handle installation, configuration, and troubleshooting for you. It orients to your OS, picks the right deploy path, runs BotrixAI's own setup scripts, and verifies the result. Install it once:

<CodeGroup>
```text Claude Code
/plugin marketplace add Jatin-35/dograh-plugins
/plugin install botrixai@botrixai
```
```text Codex
codex plugin marketplace add Jatin-35/dograh-plugins
codex plugin add botrixai@botrixai
```
</CodeGroup>

Then start a new session and ask it to *"set up BotrixAI"* (in Claude Code you can also run `/dograh-setup`). See [Jatin-35/dograh-plugins](https://github.com/Jatin-35/dograh-plugins) for details.
</Tip>
