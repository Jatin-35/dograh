BotrixAI runs in your browser — there is nothing to install.

## What you need

- A **BotrixAI workspace**. Sign in at [voice-app.botrixai.com](https://voice-app.botrixai.com).
- A **modern browser** — the current version of Chrome, Edge, Firefox or Safari.
- A **microphone**, and permission to use it, if you want to talk to your agent from the browser with Web Calls.

## For browser calls

Web Calls stream audio over WebRTC, so:

- The page must be served over **HTTPS**. Browsers refuse microphone access on plain HTTP origins.
- Allow the **microphone permission** prompt when it appears. If you dismissed it earlier, re-enable it in your browser's site settings.
- Corporate networks that block UDP can prevent the audio connection from establishing. If a call connects but you hear nothing, try a different network first.

## For phone calls

To place or receive real calls you also need:

- An account with a **telephony provider** — see [Telephony](/integrations/telephony/overview) for the supported ones.
- A **phone number** on that provider.

## For your own models

BotrixAI ships with a managed inference pipeline. To bring your own models instead, you need an API key from each provider you want to use — see [Model Configurations](/configurations/inference-providers).
